# No Vanilla Implant EMP Penalties

Removes EMP-induced vomiting and brain shock from vanilla Royalty and Odyssey implants.

Royalty와 Odyssey에서 추가되는 임플란트들을 장착했을 때 EMP를 맞으면 토하고 뇌충격으로 기절하는 상호작용 제거

Q. 왜 만들었나요?
(Why did you make this mod?)
A. 그냥.. 임플란트 덕지덕지 바른 슈퍼솔저 정착민이 메카노이드 상대하다가 눕는 게 싫어서
(Well... I just didn't like watching my implant-stacked supersoldiers drop unconscious while fighting mechanoids.)
